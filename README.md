# Human Body Atlas

피부→근육→골격→장기→신경/혈관 레이어로 인체를 탐험하는 생물 수업 도구입니다 (초5~중3). 절차적 Low-poly 자체 모델로 저작권 걱정 없음.

- **정적 사이트**: 서버, 로그인, DB 없음.
- **런타임 AI 없음**: 빌드 후 LLM/API 호출 없음.

## 시작하기

```bash
npm install
npm run dev
```

자세한 학습 설계는 [`구현계획.md`](구현계획.md), 변경 기록은 [`docs/UPDATELOG.md`](docs/UPDATELOG.md) 참고.
