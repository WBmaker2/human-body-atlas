## 2026-11-02

- 인체 3D 아틀라스 첫 버전을 만들었습니다 (구현계획 F1~F6 전부).
- 피부→근육→골격→장기→신경/혈관 5개 레이어를 켜고 끄거나, 투명도를 조절하거나, 하나만 따로 볼 수 있습니다(격리 모드).
- 뇌·심장·폐·간·위·소장·대장·신장·식도·입 10개 장기를 클릭하면 한글 설명 카드(하는 일·관련 질병·깜짝 상식)가 열립니다.
- 심장 박동과 혈액 흐름(속도 조절), 폐 부피와 횡격막 움직임(호흡수 조절) 애니메이션을 넣었습니다.
- 입→식도→위→소장→대장→정리 6정거장 소화 투어를 만들었습니다. 재생/정지/이전/다음과 진행 dots가 있고, 움직임 줄이기 설정에서는 카메라 자동 이동이 꺼집니다.
- 이름표 끌어서 붙이는 라벨 퀴즈(채점·다시풀기)와 선생님용 인쇄 장기표를 넣었습니다.
- 참고: 계획서의 React/R3F/Zustand/Tailwind 대신, 이미 잡혀 있던 가벼운 구조(바닐라 TypeScript + Three.js 직접 사용)로 만들었습니다. 기능은 모두 같고 설치·실행이 더 가볍습니다.
