# Human Body Atlas 업데이트 내역

## 2026-11-03

- 인체 모형이 실제 장기 모양으로 바뀌었습니다. 미국 HuBMAP HRA 공개 자료(CC BY 4.0)의 뇌·폐·기관·심장·간·소장·대장·신장·요관·췌장·방광 14종을 썼습니다. 입·식도·위·쓸개는 자체 제작 모형 그대로입니다.
- 앱 하단 "출처·라이선스 보기"에서 장기 모형의 제작자·출처·라이선스를 볼 수 있습니다.
- 실제 모형은 켜자마자 작은 것부터 차례로 불러오며(첫 방문 후에는 저장되어 다음부터 바로 나옴), 불러오다 실패해도 기존 모형이 그대로 보여 수업이 끊기지 않습니다.

- 인체 모형이 훨씬 알아보기 쉬워졌습니다. 도형 쌓기 방식 대신 장기 모양을 살리는 새 제작 방식(단면 회전·굵기 조절 튜브·표면 다듬기)으로 바꿨습니다.
- 심장은 대동맥 활과 함께, 폐는 기관·기관지와 함께, 위는 J자 모양으로, 소장은 구불구불한 결로, 뇌는 좌우 두 부분으로, 신장은 콩 모양+요관으로 보입니다. 동맥(빨강)·정맥(파랑)도 구분됩니다.
- 조명이 좋아졌습니다 (부드러운 그림자, 매끈한 장기 표면). 가슴 근육은 작게·옆으로 옮겨 심장과 폐를 가리지 않고, 근육 기본 투명도도 낮췄습니다.
- 장기가 10개에서 13개로 늘었습니다. 췌장·쓸개·방광을 클릭하면 한글 설명 카드가 열리고, 퀴즈에도 췌장·방광이 추가되어 8문항이 되었습니다.
- 카메라 투어가 3종으로 늘었습니다. 하단 투어바에서 소화 투어(6정거장)·순환 투어(5정거장)·호흡 투어(4정거장) 탭으로 골라 볼 수 있습니다.
- 휴대폰에서 두 손가락으로 모형을 확대·축소할 수 있습니다(핀치 줌). 한 손가락 회전과 버튼 선택은 그대로입니다.
- 선생님용 인쇄 장기표가 전체 13개 장기로 바뀌었습니다 (소화 순서는 숫자로 표시).

## 2026-11-02

- 인체 3D 아틀라스 첫 버전을 만들었습니다 (구현계획 F1~F6 전부).
- 피부→근육→골격→장기→신경/혈관 5개 레이어를 켜고 끄거나, 투명도를 조절하거나, 하나만 따로 볼 수 있습니다(격리 모드).
- 뇌·심장·폐·간·위·소장·대장·신장·식도·입 10개 장기를 클릭하면 한글 설명 카드(하는 일·관련 질병·깜짝 상식)가 열립니다.
- 심장 박동과 혈액 흐름(속도 조절), 폐 부피와 횡격막 움직임(호흡수 조절) 애니메이션을 넣었습니다.
- 입→식도→위→소장→대장→정리 6정거장 소화 투어를 만들었습니다. 재생/정지/이전/다음과 진행 dots가 있고, 움직임 줄이기 설정에서는 카메라 자동 이동이 꺼집니다.
- 이름표 끌어서 붙이는 라벨 퀴즈(채점·다시풀기)와 선생님용 인쇄 장기표를 넣었습니다.
- 참고: 계획서의 React/R3F/Zustand/Tailwind 대신, 이미 잡혀 있던 가벼운 구조(바닐라 TypeScript + Three.js 직접 사용)로 만들었습니다. 기능은 모두 같고 설치·실행이 더 가볍습니다.
